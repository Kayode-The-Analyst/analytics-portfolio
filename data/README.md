
# Dataset

## GrandStay Intelligent Service Analytics

The analysis presented in this project was conducted using a merged operational dataset containing approximately 120,000 records and 40 variables.

The dataset was used to investigate service-level performance, escalation patterns, workload characteristics, customer experience indicators, knowledge requirements, automation opportunities, and potential predictors of SLA breaches.

### Data confidentiality

The original dataset used during the analysis is not included in this public repository.

This is because the underlying data may contain proprietary, commercially sensitive, operational, or otherwise restricted information.

No confidential or personally identifiable information from the original dataset is intentionally disclosed through this repository.

### Reproducibility

The analysis, methodology, visualisations, and findings presented in the project documentation were developed from the original dataset.

Where appropriate, a synthetic dataset may be provided in the future to demonstrate the analytical methodology without exposing the original operational data.

### Dataset characteristics

The merged dataset contained variables relating to areas such as:

- Service requests
- Customer interactions
- Escalations
- SLA performance
- Customer satisfaction
- Agent performance
- Workload and inquiry volume
- Knowledge-base requirements
- Automation opportunities
- Operational and temporal characteristics

The dataset was prepared and analysed to identify patterns and potential opportunities for intelligent service management and predictive decision support.

### Research context

The dataset supports an applied research investigation into:

- Predictive analytics
- Machine learning
- Intelligent service analytics
- SLA breach prediction
- Operational decision support
- Process automation
- Customer experience analytics

The purpose of the analysis is not simply to produce descriptive dashboards, but to investigate how operational data can be transformed into actionable insights and potentially predictive decision-support systems.
